# Fairy Companion v0.3.2 — Windows 社区预览版

面向 Codex 的非官方 Fairy 风格桌面伴随组件，支持 HDD 配色、可选开屏、本地语音和人设技能。

## 下载与安装

- 普通使用者下载 `Fairy-Companion-v0.3.2-windows-x64.zip`，解压后阅读 README，安装 Python 3.12 x64 并运行 `Install.cmd`。
- 开发者可下载 `Fairy-Companion-v0.3.2-source.zip`，或克隆源码仓库。
- `.sha256` 文件用于校验对应 ZIP。程序尚未进行代码签名。

## 本版更新

- **语音稳定性**：避免覆盖播放器仍占用的问候音频；新回复按顺序排队，增加瞬时错误重试、服务重启后的游标恢复及断线重连。
- **浮窗操作**：左键拖动并记住位置，右键切换“始终置顶”或“回到左下角”。
- **气泡收起**：无朗读10秒后渐隐；操作键鼠后有2秒缓冲。支持“×”和菜单手动隐藏，再从菜单唤出。
- **常驻气泡**：新增“始终显示气泡”，开启后停用自动消隐，偏好会保留到重启。
- **验证**：20项Python测试通过；本机已验证拖动位置恢复、Windows置顶标志、重连后播放，以及原生气泡计时和常驻逻辑。

## 从 v0.3.1 升级

1. 先用旧目录的 `Stop.cmd` 关闭旧服务。
2. 将新版解压到新目录并运行 `Install.cmd`。
3. 用旧版 `tools/assets.py export` 导出自己的私人素材，再将私人包导入新版；HDD界面背景可从旧目录 `app/skin/hdd-background.png` 手动复制到新版同位置。
4. 用 `Configure.cmd` 重新选择本机引擎、工具和要朗读的聊天，再启动。勿把旧版整个 `app` 或 `.venv` 直接覆盖新版。
5. 若要保留浮窗位置与开关，可在组件关闭时单独复制自己的 `app/window-settings.json`。

公开包不含私人模型、图片或音频；CPU语音合成仍有等待时间，目前仍只朗读明确绑定的单个聊天的新最终回复。

## 依赖与限制

- 当前支持 Windows 10/11 x64，需 Python 3.12 和 .NET Framework 4.8。
- 完整 Codex 配色需 Node.js 22+ 和 Codex Switch 已启用的 Dream Skin 本地连接。
- 开屏缓存需 FFmpeg；实时语音需另装兼容 GPT-SoVITS 引擎与自备授权模型。
- 公开包只含中性占位图形，不包含角色图形、游戏视频、背景、声线模型或音频；无素材时可先运行图形组件。
- 只完成当前机器及新目录迁移验证，尚未在第二台实体电脑完成全功能验收，因此作为预览版发布。

详细操作见 README、docs/MIGRATION.md 与 docs/TTS.md。请勿在 Issue 上传 config.json、聊天记录、模型或私人素材。
